How it was made

A Sonnet 5.5 worker wrote demo-session.sh and ran it once to capture real CLI output into typescript.txt. An Opus 5.5 worker wrote replay.html, a page that retypes that text on a fixed JS clock, plus storyboard.yml. A Sonnet 5.5 worker then ran shot-scraper video --mp4, which drives headless Chromium at 1280x720 and hands the WebM to ffmpeg for the MP4, and used ffmpeg again for stills. Fable 5.1 orchestrated the run overnight, unattended, with no API key.

How to evolve it

Edit the commands in demo-session.sh. Re-run it to refresh typescript.txt. Paste the new text into the TS string in replay.html. Re-run the storyboard command (in Proof below). Speed lives in the T object in replay.html: char 45, line 1200, evalLine 1000, gap 1500, hold 4000 (ms). Full table in Knobs.

Decisions

  • Driver script, not script. macOS script -q had no tty in the headless session. A bash driver that echoes each $ command line and sleeps between steps gave the same transcript shape.
  • Slower output lines. At the first speeds the video ran about 30 s. Output lines went to 1200 ms each so the cut lands in the 90 to 170 s target. It came out at 111.56 s.
  • Mock mode, no API key. Every command runs with env -u ANTHROPIC_API_KEY and --mock. The run is hermetic and free.
  • Failures stay visible. The eval scene shows the four boundary_threshold_cases failures (case-053 to case-056) and their root causes. They are deliberate and documented in docs/decision-log.md.
  • Ledger reset before recording. A stale INV-1111 Keystone Packaging entry from an earlier run sat in the ledger and failed case-011, so the baseline eval read 51/56 (91.1%). The ledger was reset, the eval re-ran at 52/56 (92.9%), and the repo's first commit 8f692f0 was made that night.
  • Typescript embedded verbatim. The replay shows the CLI output as captured, including the dash characters the eval report prints itself. This page does not quote those lines.
  • No audio. No narration, no music. The terminal carries it.
